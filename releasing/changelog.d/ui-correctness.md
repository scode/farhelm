Creating or replacing a session no longer lets an older sidebar reply close the session you just opened. Closing the notification list retries a failed read mark, and an open host-update popup follows the current step. Starting an update clears an earlier setup or uninstall message so its own result is visible.

Template search gives an exact name priority with Unicode case matching. Enter during input-method composition no longer saves an unfinished template name; `.` and `..` are refused as names, and switching a saved setup to Grok clears an unsupported workspace-trust choice. Terminal size buttons return keyboard focus at either size limit, and selecting text within a program's hyperlink does not open it. Rename and Restart with show hidden characters in refusal text; rename also shows them in the current title while preserving the editable title.
