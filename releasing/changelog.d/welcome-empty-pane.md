When there are no sessions, the desktop app welcomes you in the main pane. You can start a session, add a remote host,
open the first-session guide or send feedback from there. Help → Welcome opens the same actions whenever you need them.

Context for curation: the Welcome card that used to open by itself on a helm's first window is gone, so upgrading users
who never dismissed it will no longer see it at startup; startup now shows only announcements and upgrade highlights.
