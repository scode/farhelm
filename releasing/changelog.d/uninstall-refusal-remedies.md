When uninstalling Farhelm from a host is refused, the dialog now explains the version or identity problem and how to
resolve it. These refusals also offer Remove, which forgets the host without changing anything on it.

When another host entry reaches the same machine, the refusal names that entry and says how to remove Farhelm from the
machine through it; if that entry has since been removed, it says to press Retry on this entry and then choose
uninstall on it instead.
