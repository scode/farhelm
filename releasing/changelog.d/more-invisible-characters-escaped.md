More characters that display as nothing are now shown visibly (as `<U+…>`) wherever Farhelm shows text from a host or agent, such as session titles and host details. In the hosts panel's "adopt" prompt, which asks you to confirm that a destination is a different installation, installation identities now show every non-ASCII character visibly, so two different identities can no longer look the same there. Emoji in session titles still display normally, except the flags of regions such as England, Scotland, and Wales, whose hidden tag characters are now shown too.
