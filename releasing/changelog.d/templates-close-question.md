You can close Templates after looking at an older template without being asked to save changes you did not make.
When you edit a template or recipe, the save question appears over the dialog, where you can see it at any scroll
position.

Context for curation: the question is asked only when the draft holds edits since opening or saving that Save would
store. A change the user makes back to the stored template (picking "Don't switch" on a template saved before launcher
switches existed, say) leaves without asking, since there is nothing to save. That refinement was made while landing.
