When you close Settings with unsaved changes to custom agents, the question now names each agent instead of saying only
"Custom agent", and with more than one of them Settings stays on the page you were on instead of jumping to one of them.

When the unsaved changes are all on one page, Settings shows that page behind the question. That now includes a
Tensorlake API key typed on the Credentials page together with an open credential editor, a case in which Settings used
to stay on the page you were on.
