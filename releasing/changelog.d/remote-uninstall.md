You can now remove Farhelm from a remote host from the host list: choose **uninstall** in the host's `⋯` menu. Farhelm shows what it will remove (its service and program files on the host) and the directory where the host's Farhelm data stays, and does nothing until you confirm. It refuses, naming them, while any session on the host has not ended or still has a terminal tab open, so stop those sessions and close their tabs first; the host also has to be connected. When it is done the host leaves the list. If it fails partway, choosing **uninstall** again finishes the job.
