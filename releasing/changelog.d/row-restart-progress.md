A session's row in the list now shows "Restarting on" and the host's name, with the seconds it has waited, once a Restart takes longer than two seconds, as it already did for Replace, so you can see which sessions are still restarting without opening each one.

Before this, a Restart's wait showed only in the open session's header, its interrupted card, and the launcher's progress line for Restart with. The row's copy stays silent for screen readers while the session is open, since the header already announces it.
