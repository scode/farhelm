OpenCode now accepts model names without the `opencode/` prefix for every suggested model. Before, typing a name such as
`gpt-6-luna` with OpenCode selected either switched the launch to Codex, which offers a model of the same name, or was
refused as belonging to another harness. Typing a model name also no longer changes the harness you selected: a model
only another harness offers shows a message naming that harness instead, and picking another harness's model from the
full model list still switches to it.
