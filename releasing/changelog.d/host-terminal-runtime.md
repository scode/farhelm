Nothing user-facing yet: this adds the supervisor's side of a terminal running in a terminal host (reading its output
into the supervisor's own terminal emulator, answering the program's terminal queries, drawing a frame the program left
unfinished, following the program's exit, and passing input, resizes and shutdown to the host). Nothing in the product
uses it until a later change turns new terminals on; that change carries the real entry.
