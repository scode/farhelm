The Claude Code, Codex, Muse and Pi trust switches now apply in any directory on a new launch. If you already turned a
switch on, it now applies in directories you choose yourself as well as in managed checkouts. Claude's saved trust
entries can accumulate as you open more directories. Farhelm does not mark your home directory or the root directory
trusted for Claude, because Claude would then trust every directory inside it.
