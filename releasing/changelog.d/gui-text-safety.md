Pasted text can no longer use hidden end-of-paste markers to send the rest as typed input. Farhelm removes Escape characters from pasted and dropped text. Template summaries show hidden and direction-changing characters in model names, and installation identities show spaces visibly. Saving a template refuses control or invisible formatting characters in its launch or resume command; existing templates still launch, but their commands must be fixed before any edit can be saved.
