You can now make the text in terminals larger or smaller: press Cmd+Shift with + or − on macOS (Ctrl+Shift on Linux),
or use the A− and A+ buttons at the right end of a session's terminal tabs. Every open terminal changes together, and
the programs running in them see the new size. Each browser or desktop app remembers its own size. On Linux the
shortcut takes over Ctrl+Shift+− inside the terminal, which some shells and editors use as undo.
