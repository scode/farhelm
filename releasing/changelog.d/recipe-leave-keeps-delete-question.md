In Settings → Recipes, choosing **Keep editing** in "Save these changes before leaving?" no longer drops a recipe's
open Delete question: you come back to the editor with the question still waiting for your answer. Choosing **Save**
still takes it away, as it does when you save on closing Settings.

Previously, merely asking whether to save before going Back took the Delete question away, even when you then chose to
keep editing. Settings' own "Save changes before closing?" already left it in place on Keep editing.
