New sessions can start with an initial prompt from the session launcher, command line or a launch template, sent once
when the agent starts. Remote hosts need an Update after upgrading Farhelm.

Goose, Pi and custom commands do not accept prompts, and Muse cannot combine one with a named conversation. Inherited
spawns refuse prompt flags.

The initial-prompt box starts compact enough for the populated session launcher to fit a 1440×900 window, including after choosing an agent and model, and remains vertically resizable for longer messages.
