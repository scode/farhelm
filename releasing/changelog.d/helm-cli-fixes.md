Closing or reloading the feedback page while feedback is sending no longer cancels the send. Planning a host update or removal finishes its cleanup even if you close the page, and stopping a host connection immediately after it starts no longer leaves it connecting in the background. After setup with a custom state directory, the sign-in command points at that helm; token rotation refuses a state path that cannot be represented faithfully. Literal environment-reference text in the helm state path no longer breaks SSH connections. Unsent Codex drafts containing question-shaped text no longer make the sidebar ask for an answer.
