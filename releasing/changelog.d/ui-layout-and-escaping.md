After the helm is updated, Restart and Replace at the top of an open session refresh the session list, and newly discovered terminals wait for you to take control instead of taking a session away from another window.

Marking a session read or unread sends your latest choice even when an earlier identical choice is still being saved.

Host menus remain reachable in a 240px sidebar, and ended-session actions remain reachable in a 650px main area. Repeated session refresh failures now say that the displayed state may be old. Host Settings waits while an uninstall plan is being prepared, and refused permission changes restore the switches.

Rename shows hidden characters without changing an untouched title. Saving a template whose session name contains hidden characters, including joined emoji, is now refused; existing templates still launch. Approvals-only templates can retain every approval choice without setting an agent type, and deleting a template waits for its saved version to finish reloading.
