The session launcher now shows the two kinds of launch as two tabs, agent and command, in place of the "other / command" button among the agents; typing "command" in the search box no longer offers it either, so use the command tab. Each tab keeps what you entered on it when you switch to the other, and only the selected tab's launch starts. On the command tab, picking an agent, a model or a recent setup in the search box switches to the agent tab; picking a folder, a host or a name keeps the command tab. The arrow keys move between the two tabs.
