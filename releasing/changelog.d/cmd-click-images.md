In the desktop app, Cmd-click (Ctrl-click on Linux) on a file path in a terminal now also opens PNG, JPEG, GIF, WebP,
BMP and AVIF images in your default app after downloading them, alongside Markdown, text and JSON files. Settings no
longer warns about these image types. SVG still gets its warning.

This changes only the default for **File types to open with Cmd-click**. If you have ever saved that field, even
without editing it, or saved it empty, your saved list stays as it is; add the image types to it yourself if you want
them.
