The host half of comparing an agent's retried create by the request it sent. Nothing changes for users until the helm
sends that comparison, which the following change does and describes in agent-retry-by-request.md. On its own, this only
stops the host's refusals of a create made with an idempotency key from quoting the key, which for an agent's create was
an internal form the agent never typed.
