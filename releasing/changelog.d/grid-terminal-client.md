Nothing user-facing yet: this adds the browser and desktop app's terminal for terminals that run in a terminal host,
which draws the screen the supervisor's emulator sends instead of running xterm.js, with today's scrollback, selection
and copy, paste, links (including the hyperlink warning, file-path downloads and tunnels) and reconnect behavior. Every
terminal is still a tmux terminal shown by xterm.js until a later change turns new terminals on; that change carries the
real entry.
