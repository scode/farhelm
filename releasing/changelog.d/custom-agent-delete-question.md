Deleting a custom agent in Settings now asks the same way other deletes do: the question names the agent, starts on Cancel, and Escape cancels the delete instead of closing Settings. Saving your changes when you close Settings no longer refuses while that question is open.

Previously the question was two plain buttons that never named the registration, Escape could close Settings with the delete still pending, and Save on close was refused with "Save was blocked" until the delete was cancelled. The unanswered question is now simply dropped when you choose Save.
