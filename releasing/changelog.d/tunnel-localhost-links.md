Pages on other local ports can no longer open the browser helm through an ordinary link. Opening it from the address
bar or a bookmark still works.

The localhost-tunnel protocol requires remote hosts to be updated before they can connect to this build.

The Mac app can keep session-owned localhost tunnels until you close them, delete the session, or quit the app. Tunnels
require an explicit shared consent choice; turning it off closes active connections as well as the listening ports.
