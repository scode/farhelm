The trash beside New lists archived managed checkouts by host, with disk usage and where to copy work out before
cleanup. You can permanently delete all archived checkouts on one host or across reachable hosts, after confirmation.
Unreachable hosts are skipped, unknown sizes make totals partial, and cleanup failures name what could not be removed.
Deleting the last session using a managed checkout plays a short cue into the trash, unless reduced motion is enabled.
