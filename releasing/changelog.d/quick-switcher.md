Press Cmd+K on macOS or Ctrl+Shift+K elsewhere to search sessions across every host and jump to one from the keyboard, even from a focused terminal. Name matches come before host or directory matches, with recently active sessions first. Escape returns focus to where you were. Type a new session name or use `tl:` to find a template, then open the session launcher with it filled in. Review the draft and press Launch to start it.
