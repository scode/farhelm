The sidebar now has a host rail for filtering sessions, with each host's mark and state, and Settings and Help at its
foot. Hosts opens the complete host management panel in place of the session list; setup, updates and other host work
continue when it is closed. The list's sort order is its title, Compact lives in that menu, and Trash, Templates and New
use compact icon buttons. A status choice below the title shows All, Running, Waiting or Idle sessions. Picking a hidden
session through the quick switcher returns both host and status choices to All.

If setup or Update fails or its result is uncertain while Hosts is closed, a warning stays on that host's icon until
Hosts is opened or that action succeeds on a later run. Hosts never opens by itself.
