Every button and every icon that means something now explains itself when you rest the pointer on it: the local and
remote host marks, the session and host menus' toggles, the session header's replace, clone and delete buttons, terminal
tabs, the controls in the new-session form and in the hosts list, and plain-word buttons such as **cancel**, whose hover
text says what cancelling leaves as it is. Menu items that already show a description under their name are unchanged.
