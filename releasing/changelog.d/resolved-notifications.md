Session warnings about a missing conversation or an agent that has not said which conversation it is in now stay in the notification list marked resolved once Restart can resume again, and no longer make the bell red. If the same problem returns before the agent is relaunched, its warning becomes new and unread again, even if it had been cleared.

After upgrading, downgrading to a version from before this change prevents that host's supervisor from starting, including the one managed by the desktop app.
