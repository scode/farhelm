Nothing a user can see changes. In the desktop app, the security warning shown before something first goes through a
host tunnel (a terminal link, an approval card's "tunnel and open", or turning tunnels on in Settings) now acts only for
the warning its Allow, Cancel or Escape was drawn for. No way for a different warning to be open in between was found,
so this is for consistency with the other confirmations.
