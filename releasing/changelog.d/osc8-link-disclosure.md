Terminal hyperlinks with descriptive labels no longer show a mismatch warning just because the label includes a URL in parentheses. Concealed text inside a program's hyperlink no longer affects the warning or responds to hovering and clicking.

A label that starts with a bracket or quote, such as `<https://example.test/>`, no longer counts as a web address, so it gets the ordinary display naming the real destination rather than the mismatch warning.
