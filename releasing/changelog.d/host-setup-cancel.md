Cancelling the setup question when adding a host now always cancels it. Clicking **cancel** (or pressing Escape) and
then, in quick succession, **yes** or **yes, and don't ask in the future** could still set up Farhelm on the remote
machine. On a host already in the list, cancelling its setup question and then quickly answering **yes, and don't ask in
the future** set nothing up but still turned the question off for every host you add later.
