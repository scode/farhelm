Nothing user-facing yet: once a host creates new terminals, a session that still runs in an old (tmux) terminal shows a
band suggesting a restart when convenient (or a clone or replace when it cannot restart), a session whose agent is new
but whose tabs are old suggests reopening those tabs, the bar under the terminal names each terminal's kind, and a new
docs page, "Move sessions to new terminals", explains the change (a draft, left out of the published site until then).
No host creates new terminals until a later change turns them on, so nothing shows before then; that change carries the
real entry, which should mention the band and link the page.
