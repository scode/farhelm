The session switcher and template launcher now use the session launcher's search style. The switcher shows each
session's agent, host, status and most recent activity at a glance, with search examples when the field is empty.
The template launcher marks templates that need more choices before they can start a session.
Rename opens straight to the title field, with the agent, host, directory and status underneath. Group names use the
same editor.

The switcher's key hints at the bottom read as one sentence to a screen reader.
