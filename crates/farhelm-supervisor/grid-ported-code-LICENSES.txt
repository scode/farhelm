This file carries the license notices for code that Farhelm ported from
xterm.js into its supervisor's input encoder. The port is Farhelm source,
not a vendored copy, so this notice stands on its own; xterm.js itself no
longer ships with Farhelm.

The code was ported from @xterm/xterm 6.0.0. Where it lives:

- crates/farhelm-supervisor/src/grid_input.rs, compiled into the farhelm
  binary: key encoding (evaluateKeyboardEvent), mouse report encoding
  (CoreMouseService, and CoreBrowserTerminal's wheel on the alternate
  screen), and paste line endings (prepareTextForTerminal,
  src/browser/Clipboard.ts).

The old Dioxus UI's grid terminal also carried ports from xterm.js, its
@xterm/addon-fit 0.11.0 and @xterm/addon-web-links 0.12.0 add-ons, and the
part of Visual Studio Code's vs/base that xterm.js 6.0.0 compiles in. Those
JavaScript ports were deleted with that UI (GPUI migration, F1); their
notices below are kept unchanged.

This file is embedded in every farhelm binary, which compiles the encoder,
and `farhelm licenses` prints it. (It used to ship inside the web bundle
that binary embedded; that bundle is gone.) THIRD_PARTY_NOTICES.md at the
repository root records it for the source tree.

The xterm.js text is copied verbatim from the LICENSE file of @xterm/xterm
6.0.0 as published to npm; the add-ons' texts from their own LICENSE files;
the Visual Studio Code text from LICENSE.txt at the root of
https://github.com/microsoft/vscode, which the vs/base sources cite.
