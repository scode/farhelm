# Old-terminal warning notes misattribute query replies

Reviewed commit: 407a49435278844248d573083fdea6e23fd96c02

## TLDR

A new maintenance comment attributes all automatic old-terminal replies to the browser, although ordinary device and
cursor queries are answered inside tmux and removed before reaching it. This misstates the warning's input path; no
changed execution or user-visible malfunction is claimed.
