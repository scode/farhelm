Steel: reference mockups

The visual reference for the Steel redesign plans. These are mockups, not captures: sizes are approximate, and the plans’ written design and SPEC.md win wherever a picture and the words disagree. Session, host and path names are invented. The maintainer approved these pictures; change them only with the maintainer’s agreement.

Main window, dark

Steel. Host rail with All selected and each host’s own icon and color; sort order as the list title with the session count; status filter slide; status shapes; solid selection; icon-and-label actions with split Restart and Replace; tunnel pill beside the tabs; session bar at the bottom. Rows are shown in compact mode; the non-compact two-line mode and its default stay as they are.
