# GPUI foundation ownership

NOTE: This is a first version, written while the foundations are still being built (milestone M1). It covers what exists
so far and is completed for the M1 report, including the landing-step script that will read it.

Each app-wide concern of the GPUI app has one owner (SPEC_impl.md, "GUI architecture"). This table says which paths each
owner holds, and which of them are extension points: places an area may add to without asking, as long as the addition
follows the pattern already there. Every other change to an owned path is requested through the orchestrator (a
foundation-change request in the area's outbox), never made directly by an area. The lint exceptions column counts the
`#[allow]`s that let an owner make the one call `crates/gui/clippy.toml` bans everywhere else.

Paths are relative to the repository root; a path ending in `/` covers everything under it.
