A guided first run: launch an agent from the [launch dialog](/docs/using/start-a-session/), watch its status dot change
in the [session list](/docs/using/session-list/), close the window, come back, and find the session still running. That
last step is the moment the product makes sense, so the walkthrough ends on it and links to
[What survives what](/docs/how-it-works/what-survives-what/).
