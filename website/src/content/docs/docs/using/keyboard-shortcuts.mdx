Press **Cmd+/** on a Mac, or **Ctrl+Shift+/** on Linux, to see your shortcuts in Farhelm. You can also choose
**Keyboard shortcuts** from the **?** menu below Settings. The dialog shows the keys for the computer you are on, with
the names of your current **⚡** and number-key templates. Escape, **Close**, or a click outside returns you to where you
were.

The shortcut works while you are typing in a terminal and does nothing while another dialog is open. It uses the
physical slash key; on Linux, keep Shift held even if that key types `?`. The open session's menu and the **?** menu
also show shortcuts beside their commands.

## Sessions

Most shortcuts use Command on a Mac and Ctrl+Shift on Linux. Two differ: the Linux app has no shortcut for a new
session, and Delete uses Backspace there.

| Action | Mac | Linux |
| --- | --- | --- |
| [New session](/docs/using/start-a-session/) | Cmd+N | Use **+** (New session) |
| [Delete the open session](/docs/using/stop-restart-resume/#stop-or-delete) | Cmd+W | Ctrl+Shift+Backspace |
| [Rename the open session](/docs/using/session-list/#rename-it-or-mark-it-read) | Cmd+L | Ctrl+Shift+L |
| [Quick switcher](/docs/using/session-list/#jump-with-the-keyboard) | Cmd+K | Ctrl+Shift+K |
| Keyboard shortcuts | Cmd+/ | Ctrl+Shift+/ |

Delete uses the same confirmation as the session's Delete button. On a Mac, Cmd+W deletes the session; the window's
close button or Cmd+Q closes the app. On Linux, Ctrl+Shift+Backspace in a text field other than the terminal does not
delete the session.

## Launching

[Launch templates](/docs/using/launch-templates/) save choices you can reuse or combine. Their shortcuts follow the same
pattern: Command on a Mac, Ctrl+Shift on Linux.

| Action | Mac | Linux |
| --- | --- | --- |
| Search templates by name | Cmd+J | Ctrl+Shift+J |
| Start the **⚡** template | Cmd+P | Ctrl+Shift+P |
| Start a number-key template | Cmd+0–9 | Ctrl+Shift+0–9 |
| Begin a launch sequence | Cmd+X | Ctrl+Shift+X |

Number shortcuts use the number row, not the numeric keypad. Open **Keyboard shortcuts** in Farhelm to see which
templates you have assigned.

The **⚡** and number shortcuts start a session directly when the template has enough choices. With the session
launcher open, they apply the template to your draft instead, leaving **Launch** to you. Other dialogs keep the
keyboard. See [Quick launch](/docs/using/launch-templates/#quick-launch) for what happens when a template needs more
choices.

### Inside a launch sequence

After the sequence prefix, queue templates in the order you want to apply them:

| Key | Action |
| --- | --- |
| Type a template name | Start or continue a word; digits within a word are part of its name |
| Space | Queue the word |
| Tab | Complete a uniquely matched name and queue it |
| Backspace | Remove the last character of the word; queued templates stay |
| 0–9 with no word in progress | Queue that key's template |
| The usual number shortcut's chord | Queue any word in progress, then that key's template |
| The **⚡** chord from the table above | Queue any word in progress, then the marked template |
| Enter | Launch the combined setup, or apply it to an open session launcher |
| Escape | Cancel the sequence |

Later templates override earlier choices. Enter with nothing queued cancels. Outside the session launcher, text fields
keep the sequence prefix's normal action; inside the launcher, a field with text selected keeps its usual action too.
See [Combine templates from the keyboard](/docs/using/launch-templates/#combine-templates-from-the-keyboard) for an
example and what cancels a sequence.

## Editing text

In Farhelm's text fields on Mac and Linux, Ctrl+F and Ctrl+B move forward and back by a character. Ctrl+N and Ctrl+P move
down and up, including through a field's suggestions. Ctrl+A and Ctrl+E go to the start and end of the line. Ctrl+D and
Ctrl+H delete forward and back, and Ctrl+K deletes to the end of the line. On Linux, this leaves text fields without a
Select All shortcut. In a focused terminal, these keys go to your program.

In [Settings](/docs/using/settings/), Cmd+F on a Mac, or Ctrl+F on Linux outside a text field, moves to **Search**.

## Terminal

These shortcuts change the text size of [your session terminals](/docs/using/work-in-a-session/#open-a-shell-beside-the-agent),
as the magnifier buttons do. They work while a terminal is open, including when focus is elsewhere in Farhelm. Unlike
the other shortcuts, they take Shift on a Mac too.

| Action | Mac | Linux |
| --- | --- | --- |
| Larger terminal text | Cmd+Shift+Equal | Ctrl+Shift+Equal |
| Smaller terminal text | Cmd+Shift+Minus | Ctrl+Shift+Minus |

Equal and Minus mean those physical keys (the `+` and `−` positions on a US keyboard).

These keys belong to the terminal itself and work while focus is in it.

| Action | Mac | Linux |
| --- | --- | --- |
| Scroll back a page | Shift+PageUp | Shift+PageUp |
| Scroll forward a page | Shift+PageDown | Shift+PageDown |
| Paste | Cmd+V | Ctrl+Shift+V or Shift+Insert |
| Select all of the terminal's text | Cmd+A | |
| Copy the selection | Cmd+C | |

On Linux, selecting text copies it, as it does on a Mac
([Copy, paste, and links](/docs/using/work-in-a-session/#copy-paste-and-links)), so there is no copy key, and Ctrl+A and
Ctrl+C go to the program.
