How to start a session: the session launcher and its choices (harness, model, effort, permissions, workspace trust),
recent setups, choosing the host and working directory, and starting from a fresh GitHub checkout. Also the confirmation
a YOLO launch asks for on a sensitive host, which is set per host in [Manage hosts](/docs/using/manage-hosts/). Which of
those choices each agent supports is in [Supported agents](/docs/agents/); running something that is not a supported
agent is in [Custom commands and profiles](/docs/agents/custom-commands/).
