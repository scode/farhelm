How to start a session: the launch dialog and its choices (agent, model, effort, permissions, workspace trust), recent
setups, choosing the host and working directory, and starting from a fresh GitHub checkout. Which of those choices each
agent supports is in [Supported agents](/docs/agents/); running something that is not a supported agent is in
[Custom commands and profiles](/docs/agents/custom-commands/).
