title: Farhelm documentation
description: Documentation for running Farhelm and the coding agents it manages.
---

Farhelm runs coding-agent sessions across your machines and keeps them one keystroke away. These pages cover the
individual agent harnesses it can launch and the mechanisms behind launching and resuming them.

The documentation is in the middle of moving here from the repository's `docs/` directory; pages not yet on this site
are still readable on [GitHub](https://github.com/scode/farhelm/tree/main/docs).
