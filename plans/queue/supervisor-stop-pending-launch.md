# Goal: Refuse Stop on unconfirmed launches with no main terminal

Refuse `Stop` on a half-started session whose launch was never confirmed and that has no main terminal, returning a
clear error directing the user to `Delete` (or `Restart`) the session instead — eliminating false-success `Stop` replies
without introducing a new durable Stop-sweep state machine or schema migration.

**Source TODO entry (removed in the last code PR):** `Settle an unconfirmed agent start before Stop reports success.`
under `## Plan follow-ups` in `TODO.md`.

## Acceptance criteria

- In `handle_stop_session` (`crates/farhelm-supervisor/src/service/handlers.rs`), `Stop` refuses any session whose
  launch is unconfirmed with no main terminal (`terminal_less_launch_may_be_live(&entry)`), regardless of
  `refuse_if_agent_running`, with a clear user-facing message directing the user to Delete (or Restart) the session
  instead.
- Refusing `Stop` leaves the session's launching state and launch record intact (never committing `ObservedExit` or
  claiming the session stopped).
- `Delete` and `Restart` continue to settle unconfirmed launches and clean up lingering startup processes as before.
- `SPEC.md` ("Lifecycle operations") notes that `Stop` is refused on an unconfirmed launch with no main terminal in
  favor of `Delete` or `Restart`.
- Tests in `host_creates.rs` (and unit tests if helpful) confirm that an authorized `Stop`
  (`refuse_if_agent_running: false`) against an unconfirmed terminal-less launch refuses cleanly, preserves the launch
  record, and lets `Delete` settle it afterwards.

## Decisions already made

- **Refuse Stop and direct to Delete / Restart:** Do NOT build a durable pending-Stop sweep state machine or schema
  migration; `Delete` already settles all launch records and scopes durably, and a never-started session has no main
  terminal to preserve.
- **Review gate:** Single fresh-context Opus 5.5 agent at high effort with the general review charter below.
