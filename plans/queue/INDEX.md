# Plans queue

One line per plan that has not landed, in queue order, oldest first. `plans/AGENTS.md` describes the states; only `scripts/plans-queue.py` changes them, and planning PRs add new `[pending]` (or, when the maintainer asks, `[held]`) lines, at the end unless the maintainer places them elsewhere. A landed plan moves to `plans/REPORTS.md` until the maintainer has reviewed its report. This file is excluded from dprint so a line is never rewrapped.

- [blocked] `environment-agent-operations.md` — Agents in sandbox and container sessions can ask Farhelm to act within their own environment, environments live until their last session is deleted, and agents elsewhere can launch sessions in new environments behind an always-asking approval card (after `podman-environments.md`)
- [landing aacdef] `sandbox-suspend-overlap.md` — A sandbox Suspend or Resume no longer blocks launches on other hosts (refused only while this page launches on or wakes that host), and a launch's wake waits out a busy host and fails fast if the host is suspended again
- [pending] `wake-launch-stuck.md` — A quick launch whose retry after waking a sandbox host is refused shows its launcher again instead of an invisible one blocking the page, and the page's wait to see the woken host connect gives up after 60 seconds with an error (after `sandbox-suspend-overlap.md`)
- [complete] `session-action-leftovers.md` — A Restart finished while another session was open is forgotten once the list shows that session running, so a later reboot shows the interrupted card again, and Replace with's "Replacing…" progress always clears
- [complete] `version-dblclick-flake.md` — Find out, on main from before nonblocking-session-actions and today, why double-clicking the header's version text sometimes selects nothing in Chromium, then fix the test or record a latent flake
- [complete] `cmd-click-images.md` — Cmd-click opens png, jpg, jpeg, gif, webp, bmp and avif files by default, without a warning in the settings dialog
- [pending] `tmux-end-old-terminals.md` — A new supervisor turns off the private tmux server it finds and marks the sessions that ran in it as interrupted with a notification, Restart always starts a new terminal, and the tmux driver, the two terminal kinds, byte streams and xterm.js are gone from the supervisor, helm, protocol and page
- [pending] `tmux-drop-from-install.md` — tmux is no longer required, probed, installed or shipped: setup, the desktop app, Linux provisioning, uninstall, the installer and the release payloads lose it, and Update removes Farhelm's bundled copy (after `tmux-end-old-terminals.md`)
- [pending] `tmux-drop-from-tooling.md` — Test tooling, CI, the release workflow, the brick test and agent instructions no longer build, pin, record or mention tmux; the shutdown's tests use whatever tmux the machine has (after `tmux-drop-from-install.md`)
- [pending] `tmux-drop-from-docs.md` — Specs, docs, comments and rationales describe one kind of terminal, the remaining TODO.md wording is updated, and a final audit accounts for every remaining tmux and xterm.js mention (after `tmux-drop-from-tooling.md`)
